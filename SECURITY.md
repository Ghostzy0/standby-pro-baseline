# Historical baseline security policy

This is a source archive, not an accepted production phone release. The original app automatically requests London weather from Open-Meteo, which receives IP and fixed coordinates. Preferences remain local. It has unused sensitive permission declarations, sample calendar/music data and original debug release signing; these are historical limitations, not recommended release patterns.

Do not post credentials, real events, private screenshots or device identifiers in public issues. Use GitHub private reporting if enabled, or a private contact route available from the owner. No response-time guarantee. Active security hardening belongs in https://github.com/Ghostzy0/standby-pro . Verify PROVENANCE.json before generating build files and compare release SHA256 manifests before use.

Original source is MIT; dependency licences are separate. Open-Meteo data is CC BY4.0; the free API endpoint is noncommercial. No paid service fallback or production signing identity is supplied.
